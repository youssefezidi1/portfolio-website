How I workMa façon de travailler

A high Dice score is not a result. A usable tool is.Un Dice élevé n'est pas un résultat. Un outil utilisable en est un.

My background combines clinical engineering and machine learning. So I start with the decision the output supports, who reads it, and what happens when the model is wrong — then I choose the architecture.Mon parcours combine l'ingénierie clinique et le machine learning. Je commence donc par la décision que la sortie doit soutenir, par qui la lit, et par ce qui se passe quand le modèle se trompe — puis je choisis l'architecture.

That means reviewing segmentations case by case with clinicians rather than trusting an average, reporting the structures where a model underperforms as plainly as the ones where it shines, and finishing the job: a model nobody can run has not been delivered.Concrètement : relire les segmentations cas par cas avec les cliniciens plutôt que de se fier à une moyenne, rapporter aussi clairement les structures où le modèle échoue que celles où il excelle, et aller au bout : un modèle que personne ne peut lancer n'est pas livré.
